# coat pocket

Phone-first notes on the games and apps we ship.

A static Astro site. Web Dev deploys.

## New post

1. Add `src/content/posts/<slug>.md` with frontmatter: title, date (YYYY-MM-DD), kind (`game` or `app`), hero, dek, and optional url.
2. Put the screenshot in `public/covers/`.
3. Web Dev deploys.
